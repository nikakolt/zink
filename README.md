# ZINK — конструктор зинов

Бесплатный онлайн-конструктор мини-зинов из одного листа A4. «Кривенько — значит искренне».

## Как открыть
Открой `index.html` в браузере (двойной клик). Сборка и сервер не нужны.
Шрифты подгружаются из Google Fonts, поэтому нужен интернет.

## Страницы
- `index.html` — главная: 3D-книжка, на телефоне раскладывается в две страницы
- `templates.html` — библиотека шаблонов (Шаблон 1 + пустые заглушки)
- `editor.html` — редактор: заполнение готовых мест шаблона, подпись карандашом
- `print.html` — лист A4 для печати и скачивание PDF

## Как это устроено
- `css/site.css` — общие стили и адаптив (точки перелома 760 и 900 px)
- `js/tpl1-data.js` — Шаблон 1, разобранный на слои (фон, фото, текст, декор); картинки встроены,
  чтобы PDF собирался даже при открытии файла с диска
- `js/zine.js` — общее: сохранение правок в браузере (localStorage), отрисовка страниц на canvas,
  раскладка листа A4 (верхний ряд 5-4-3-2 перевёрнут, нижний 6-7-8-1), карандаш, сборка PDF без библиотек
- `js/editor.js` — логика редактора
- `js/home.js` — наклон книжки на главной
- `assets/` — фото и рисунок для главной, превью шаблона

Правки из редактора сохраняются в браузере и попадают в PDF на странице печати.

## Как выложить в интернет
Подойдёт любой статический хостинг: GitHub Pages, Netlify (перетащить папку на netlify.com/drop), Vercel.
